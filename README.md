# 赛博人物志 · 网页小游戏合集

纯前端 / 零依赖 / 双击 HTML 即玩的四个频道。

| 入口 | 文件 | 玩法 |
| --- | --- | --- |
| 主站 | `index.html` | 四合一入口 + 掌机养成（喂食/互动/休息/下一天） |
| 群像馆 | `hall.html` | 在册人物图鉴与词条查看 |
| 守卫战 | `td.html` | 塔防：布防线 + 英雄驻守 |
| 突围战 | `sd.html` | 割草生存：拖动走位 + 专属武学 + 升级三选一 |
| 赛博江湖 | `jianghu.html` | 武侠卡牌放置：六人布阵 / 五流派 / 招募十连 / 推图 40 阵 / 离线挂机 |

## 本地运行

```bash
git clone https://github.com/minj65446-ops/cyber-pets.git
cd cyber-pets
python -m http.server 8080     # 然后打开 http://127.0.0.1:8080/index.html
```

直接双击任意 `.html` 也能玩（`file://` 协议已验证），存档写在浏览器 `localStorage`，换域名/换协议不互通。

## 后续怎么更新

### 1. 改本地代码后推到 GitHub

```bash
git add -A
git commit -m "说明这次改了什么"
git push origin main
```

> 代理环境（GitHub 直连被阻断时）：
> `git -c http.proxy=http://127.0.0.1:7897 -c https.proxy=http://127.0.0.1:7897 push origin main`

### 2. 缓存击穿 —— 改了 JS 必须升版本号

页面 `<script src="xxx.js?v=20261022d">` 上的 `?v=` 必须同步改，否则用户浏览器还跑旧代码，会以为「改了没生效」。右上角版本徽标（如 `v1.1 · 平衡版`）也一并更新，方便肉眼确认当前版本。

一处替换，全部升版：

```bash
sed -i 's/?v=20261022d/?v=<新版本>/g' cyber-pets/*.html
```

### 3. 在线链接更新

```bash
node publish.js /项目路径 online      # 重新发布到同一条链接（地址不变）
node publish.js /项目路径 offline     # 下线
```

### 4. 小程序更新

改完本地代码 → `%APPDATA%` 或用微信开发者工具打开小程序项目目录 → 点「上传」，填版本号 + 备注 → 登录 mp.weixin.qq.com，管理 → 版本管理 → 把刚上传的版本提交审核 → 审核通过后点「发布」。

小游戏包体不得超过 4MB（目前全部资源加起来不到 1MB，无需分包）。
